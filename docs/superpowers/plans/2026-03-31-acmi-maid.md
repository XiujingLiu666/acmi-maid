# acmi-maid Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a pure-Python ACMI 2.2 toolset for parsing, writing, editing, and streaming Tacview-compatible flight recording files.

**Architecture:** A `src/acmi_maid/` package with six modules: `enums.py` (type enums), `models.py` (dataclasses), `utils.py` (transform/datetime/escape helpers), `parser.py` (file→AcmiFile), `writer.py` (AcmiFile→file), `streamer.py` (append-only real-time writer). Each module has a corresponding test file. TDD throughout.

**Tech Stack:** Python 3.10+ (stdlib only), uv for project management, pytest for testing

**Spec:** `docs/superpowers/specs/2026-03-31-acmi-maid-design.md`

    assert t.u == 100.0
    assert t.v == 200.0

    """Longitude|Latitude|Altitude|Roll|Pitch|Yaw"""

- [ ] **Step 3: Implement utils.py**

Implement all six functions as specified in the design doc:
- `parse_transform(value: str) -> Transform`: Split on `|`, map component count (3/5/6/9) to fields, empty → None.
- `format_transform(t: Transform) -> str`: Determine form (9/6/5/3) based on which fields are set, format with `|`, None → empty string. Trailing None components should be omitted (e.g. 3-form if only lon/lat/alt set), but interior Nones produce empty fields.
- `parse_acmi_datetime(value: str) -> datetime`: Parse ISO 8601 string ending in `Z`. Handle optional fractional seconds.
- `format_acmi_datetime(dt: datetime) -> str`: Format to `YYYY-MM-DDTHH:MM:SSZ`. Include fractional seconds only if non-zero.
- `split_escaped(line: str, delimiter: str = ",") -> list[str]`: Split on delimiter, respecting `\` escape. Unescape `\,` → `,` in results.
- `escape_value(value: str) -> str`: Escape `,` → `\,`.
- `to_snake_case(name: str) -> str`: PascalCase → snake_case.
- `to_pascal_case(name: str) -> str`: snake_case → PascalCase.
