# Best practics within teams

1. KISS: Keep it simple and stupid.
2. DRY: Do not repeat yourself.
3. High Cohesion, Low Coupling.
4. Handle exceptions elegantly.
5. (Python)Prefer `log` rather than `print`.
6. Write and run unit test in `./test` to verify your code after edit.
7. Keep your project structure well organized!
8. Do NOT create unnecessary `.md` files unless asked by users.
9. Update `README.md` and related comments if needed.
10. use `uv` for python package management.
